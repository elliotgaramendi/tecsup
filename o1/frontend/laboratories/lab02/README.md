# Réplica de Inside Out (Pixar) en Figma

![Inside Out - Pixar](https://images.squarespace-cdn.com/content/v1/60241cb68df65b530cd84d95/a4e8a0a2-ecf4-4795-bb0a-157d8a7ddefb/d150_20mpub.pub16.101.jpg)

## 📝 Descripción del Proyecto
Este proyecto es una réplica de la página web de la película "Inside Out" de Pixar, desarrollada como ejercicio práctico para aprender Figma. El objetivo principal fue aplicar los conceptos básicos de diseño de interfaces y familiarizarme con las herramientas de Figma, siguiendo la guía introductoria desarrollada en clase.

- [Página Original de Inside Out](https://www.pixar.com/inside-out)

## 🛠️ Herramientas Utilizadas
- Figma (Herramienta de diseño)
- Navegador web para capturar referencias
- Imágenes de Inside Out utilizadas con fines educativos

## 🎯 Objetivos de Aprendizaje
- Dominar la interfaz básica de Figma
- Practicar la creación de frames y componentes
- Implementar Auto Layout para estructuras responsivas
- Trabajar con imágenes y textos
- Replicar un diseño profesional existente

## 🚀 Proceso de Desarrollo

### 1. Análisis del Sitio Original
Antes de comenzar la réplica, analicé detalladamente la página de Inside Out, identificando:
- Estructura de la navegación
- Secciones principales
- Uso de colores y tipografía
- Espaciado y alineación
- Elementos interactivos

![Screenshot del sitio original](https://images.squarespace-cdn.com/content/v1/60241cb68df65b530cd84d95/a4e8a0a2-ecf4-4795-bb0a-157d8a7ddefb/d150_20mpub.pub16.101.jpg)

### 2. Configuración Inicial
- Creé un nuevo proyecto en Figma
- Configuré un frame Desktop (1440px de ancho)
- Definí los colores principales como estilos de color:
  - Azul principal: #2D3791
  - Amarillo (Joy): #FBE34A
  - Azul (Sadness): #3AA9DE
  - Rojo (Anger): #E22626
  - Verde (Disgust): #3FBD5C
  - Púrpura (Fear): #B767CE

![Paleta de colores](https://images.squarespace-cdn.com/content/v1/60241cb68df65b530cd84d95/a4e8a0a2-ecf4-4795-bb0a-157d8a7ddefb/d150_20mpub.pub16.101.jpg)

### 3. Desarrollo de Componentes

#### Header
- Logotipo de Pixar
- Menú de navegación (FILMS, TECHNOLOGY, CAREERS, MORE)
- Implementación de Auto Layout horizontal para la navegación

![Header](https://images.squarespace-cdn.com/content/v1/60241cb68df65b530cd84d95/b8fc80ce-86ac-4607-af19-1044cbebd5e0/OT1.jpg)

#### Hero Section
- Imagen principal con el logo de Inside Out
- Fondo con curva en la parte inferior
- Título principal "INSIDE OUT" con tipografía distintiva

![Hero Section](https://images.squarespace-cdn.com/content/v1/60241cb68df65b530cd84d95/b8fc80ce-86ac-4607-af19-1044cbebd5e0/OT1.jpg)

#### Sección "Growing Up Can Be A Bumpy Road..."
- Título y párrafo explicativo
- Diseño centrado con márgenes consistentes
- Espaciado adecuado entre elementos

#### Sección de Trailers
- Título "Trailers"
- Dos imágenes con etiquetas (Teaser y Trailer)
- Auto Layout para mantener el espacio uniforme

![Trailers Section](https://images.squarespace-cdn.com/content/v1/60241cb68df65b530cd84d95/b8fc80ce-86ac-4607-af19-1044cbebd5e0/OT1.jpg)

#### Sección de Personajes
- Título "THE CHARACTERS"
- Perfil circular de cada personaje (Joy, Sadness, Anger, Disgust, Fear)
- Descripción de cada personaje
- Galería de imágenes para cada personaje

![Characters Section](https://images.squarespace-cdn.com/content/v1/60241cb68df65b530cd84d95/b8fc80ce-86ac-4607-af19-1044cbebd5e0/OT1.jpg)

### 4. Detalles y Refinamiento
- Ajusté el espaciado para que coincidiera con el original
- Refiné las curvas de los fondos
- Aseguré que las proporciones fueran correctas
- Organicé las capas con nombres descriptivos
- Implementé efectos sutiles como sombras donde era necesario

## 💡 Desafíos y Soluciones

### Desafío 1: Curvas en los Fondos
**Solución:** Utilicé la herramienta Pen para crear formas personalizadas que luego rellené con el color de fondo adecuado.

### Desafío 2: Disposición de los Personajes
**Solución:** Implementé un Auto Layout vertical para la sección de personajes, con componentes individuales para cada perfil.

![Auto Layout para personajes](https://images.squarespace-cdn.com/content/v1/60241cb68df65b530cd84d95/a4e8a0a2-ecf4-4795-bb0a-157d8a7ddefb/d150_20mpub.pub16.101.jpg)

### Desafío 3: Espaciado Consistente
**Solución:** Utilicé una cuadrícula base y Auto Layout con espaciado uniforme para mantener la consistencia en todo el diseño.

## 📚 Aprendizajes

- **Auto Layout:** Aprendí cómo esta función facilita enormemente la creación de diseños responsivos y mantiene el espaciado coherente.
- **Componentes:** Comprendí el valor de crear componentes reutilizables para elementos como tarjetas de personajes.
- **Organización:** Descubrí la importancia de nombrar y organizar adecuadamente las capas para proyectos complejos.
- **Atención al detalle:** Mejoré mi capacidad para identificar y replicar detalles sutiles que marcan la diferencia en un diseño profesional.
