# 🔗 Laboratorio de Sets en Python 🐍✨

Laboratorio práctico para dominar el uso de **sets** en Python a través de 5 retos progresivos que cubren las operaciones fundamentales de conjuntos.

## 📋 Contenido

```
/ 📁
├── 📄 README.md           # Este archivo - Información del laboratorio
├── 📄 guide.md            # Guía completa con retos y explicaciones
└── 🐍 main.py             # Soluciones implementadas con tests
```

## 🎯 Objetivos de Aprendizaje

Al completar este laboratorio, dominarás:

- ✅ **Crear y manipular sets** usando métodos básicos
- ✅ **Eliminar duplicados** de colecciones automáticamente  
- ✅ **Realizar operaciones de conjuntos** (unión, intersección, diferencia)
- ✅ **Verificar membresías** de manera eficiente
- ✅ **Convertir entre tipos** de datos (listas ↔ sets)

## 🔗 Retos Incluidos

### 🗑️ **s10.1 - Eliminador de Duplicados**
Aprende a usar sets para limpiar datos duplicados y calcular estadísticas de limpieza.

### 🤝 **s10.2 - Analizador de Intersecciones** 
Encuentra elementos comunes entre conjuntos y analiza similitudes.

### ➕ **s10.3 - Constructor de Uniones**
Combina múltiples sets en uno solo y analiza la eficiencia.

### ⚖️ **s10.4 - Detector de Diferencias**
Identifica elementos únicos y diferencias simétricas entre conjuntos.

### ✅ **s10.5 - Validador de Membresías**
Verifica presencia de elementos de manera eficiente.

## 🌟 Conceptos Clave Cubiertos

| Concepto           | Operador/Método                | Ejemplo                |
| ------------------ | ------------------------------ | ---------------------- |
| **Creación**       | `set()`, `{}`                  | `mi_set = {1, 2, 3}`   |
| **Intersección**   | `&`, `.intersection()`         | `set1 & set2`          |
| **Unión**          | `\|`, `.union()`               | `set1 \| set2`         |
| **Diferencia**     | `-`, `.difference()`           | `set1 - set2`          |
| **Dif. Simétrica** | `^`, `.symmetric_difference()` | `set1 ^ set2`          |
| **Membresía**      | `in`                           | `elemento in mi_set`   |
| **Agregar**        | `.add()`                       | `mi_set.add(valor)`    |
| **Eliminar**       | `.remove()`, `.discard()`      | `mi_set.remove(valor)` |
