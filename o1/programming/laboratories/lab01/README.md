# 🚀 Fundamentos de Algoritmos con PSEint

## 📝 Descripción General

Esta guía presenta una colección completa y práctica de algoritmos fundamentales implementados en PSEint, diseñada específicamente para estudiantes que inician su viaje en el mundo de la programación. Desde conceptos básicos como variables y operaciones aritméticas hasta implementaciones prácticas como calculadoras y conversores, este recurso ofrece un enfoque paso a paso para comprender y aplicar los principios del pensamiento algorítmico.

Los ejercicios están cuidadosamente seleccionados para proporcionar una base sólida en la lógica de programación, sin requerir conocimientos previos y preparando a los estudiantes para futuros desafíos más complejos.

## ✨ Características

- **Algoritmos Fundamentales Completos**:
  - 📏 Cálculos geométricos para figuras básicas
  - 🌡️ Conversión entre diferentes unidades de medida
  - 📊 Cálculos estadísticos simples
  - 💵 Sistema de facturación funcional

- **Retos Prácticos con Soluciones**:
  - 🏋️‍♂️ Calculadora de IMC con clasificación de resultados
  - 💱 Conversor de múltiples divisas internacionales
  - ⏱️ Transformación de unidades de tiempo
  - 🏷️ Sistema de cálculo de descuentos comerciales
  - 📐 Calculadora avanzada de propiedades geométricas

- **Material Educativo de Calidad**:
  - 🧪 Casos de prueba verificados para cada algoritmo
  - 🔍 Comentarios explicativos en cada sección del código
  - 📚 Organización progresiva de conceptos (de básico a avanzado)

## 🔍 Detalles de Implementación

### Estructura de los Algoritmos

Cada implementación en esta guía sigue un patrón consistente que facilita el aprendizaje:

1. **Declaración de Variables**: Definición clara de todas las variables necesarias con tipos de datos apropiados
2. **Entrada de Datos**: Solicitud de información al usuario mediante mensajes descriptivos
3. **Procesamiento**: Implementación de la lógica principal del algoritmo con comentarios explicativos
4. **Validación**: Verificación de datos ingresados cuando es necesario
5. **Salida Formatada**: Presentación de resultados de manera clara y organizada

### Características Técnicas

- **Manejo de Tipos de Datos**: Uso apropiado de variables numéricas (enteros y reales), cadenas y valores lógicos
- **Operaciones Matemáticas**: Implementación de fórmulas y cálculos desde básicos hasta intermedios
- **Estructuras Condicionales**: Uso de condicionales para la toma de decisiones y validación
- **Manejo de Entrada/Salida**: Interacción efectiva con el usuario para solicitar datos y mostrar resultados
- **Comentarios Descriptivos**: Documentación clara del propósito y funcionamiento de cada sección de código

## 💻 Uso del Material

### Requisitos Previos

- **Software**: PSEint (versión actualizada)
- **Conocimientos**: No se requieren conocimientos previos de programación
- **Hardware**: Cualquier computadora capaz de ejecutar PSEint

### Cómo Utilizar la Guía

1. **Instalación de PSEint**:
   - Descargar PSEint desde [http://pseint.sourceforge.net/](http://pseint.sourceforge.net/)
   - Instalar siguiendo las instrucciones para tu sistema operativo

2. **Trabajo con los Algoritmos**:
   - Copiar y pegar los algoritmos completos en PSEint
   - Ejecutar cada algoritmo presionando F9 o el botón de ejecución
   - Verificar los resultados con los casos de prueba proporcionados
   - Experimentar modificando los valores de entrada

3. **Aprendizaje Progresivo**:
   - Comenzar con los ejemplos básicos de la Sección 3
   - Avanzar hacia el caso de estudio de la Sección 4
   - Finalizar con los retos técnicos de la Sección 5
   - Intentar resolver los retos por cuenta propia antes de revisar las soluciones

### Personalización de Ejercicios

Estos algoritmos están diseñados para ser puntos de partida. Se recomienda:

- Modificar los mensajes de salida para hacerlos más informativos
- Agregar validaciones adicionales para mejorar la robustez
- Extender la funcionalidad con características adicionales
- Combinar varios algoritmos para crear aplicaciones más complejas

## 🚀 Puesta en Marcha

### Primeros Pasos

1. **Configuración de PSEint**:
   - Al abrir PSEint por primera vez, seleccionar el perfil "Estricto"
   - Configurar el idioma según preferencias
   - Familiarizarse con la interfaz y sus herramientas principales

2. **Ejecutando tu Primer Algoritmo**:
   - Abrir un nuevo archivo en PSEint
   - Copiar el código del algoritmo "Calculadora de Área de un Rectángulo"
   - Presionar F9 o hacer clic en el botón de ejecución
   - Ingresar los valores solicitados y verificar el resultado

3. **Visualización de Diagramas de Flujo**:
   - Después de escribir un algoritmo, presionar F8 para ver su diagrama de flujo
   - Estudiar cómo cada instrucción se representa gráficamente
   - Entender el flujo lógico del algoritmo a través de su representación visual
