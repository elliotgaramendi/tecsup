# 🔀 Estructuras de Control Condicional en PSEint

## 📝 Descripción General

Esta guía práctica presenta una colección completa de algoritmos y ejemplos que implementan estructuras de control condicional (if-else) en PSEint, diseñada específicamente para estudiantes que inician su camino en la programación. Desde conceptos básicos como condicionales simples hasta implementaciones avanzadas como sistemas de recomendación y validadores geométricos, este recurso ofrece un enfoque paso a paso para comprender y aplicar la lógica condicional en algoritmos.

Los ejemplos y retos están cuidadosamente seleccionados para proporcionar una base sólida en el pensamiento algorítmico, enfocándose en situaciones de la vida real donde las decisiones lógicas son fundamentales.

## ✨ Características

- **Implementaciones Fundamentales Completas**:
  - 🔀 Estructuras condicionales simples, completas y múltiples
  - 🧠 Operadores lógicos AND, OR y NOT con ejemplos prácticos
  - 📊 Sistema de calificación escolar con retroalimentación personalizada
  - 🎬 Sistema de recomendación de películas basado en preferencias

- **Retos Prácticos con Soluciones**:
  - 🗓️ Calculadora de año bisiesto con explicación detallada
  - 🏋️‍♂️ Calculadora de IMC con clasificación y recomendaciones
  - 💱 Conversor de múltiples divisas internacionales
  - 📐 Validador geométrico de triángulos con identificación de tipos
  - 📅 Calculadora de días de la semana con características adicionales

- **Material Educativo de Calidad**:
  - 🧪 Casos de prueba verificados para cada algoritmo
  - 🔍 Comentarios explicativos en cada sección del código
  - 📚 Organización progresiva de conceptos (de básico a avanzado)
  - 🎯 Explicaciones contextuales sobre la aplicación real de cada concepto

## 🔍 Detalles de Implementación

### Estructura de los Algoritmos

Cada implementación en esta guía sigue un patrón consistente que facilita el aprendizaje:

1. **Declaración de Variables**: Definición clara de todas las variables necesarias con tipos de datos apropiados
2. **Entrada de Datos**: Solicitud de información al usuario mediante mensajes descriptivos
3. **Validación**: Verificación de datos ingresados para garantizar un procesamiento correcto
4. **Procesamiento Condicional**: Implementación de la lógica de decisión mediante estructuras condicionales
5. **Salida Formateada**: Presentación de resultados de manera clara y organizada con retroalimentación contextual

### Características Técnicas

- **Manejo de Tipos de Datos**: Uso apropiado de variables numéricas (enteros y reales), cadenas y valores lógicos
- **Operadores Relacionales**: Implementación de comparaciones (>, <, >=, <=, ==, !=) para evaluar condiciones
- **Operadores Lógicos**: Uso de AND (Y), OR (O) y NOT (NO) para crear condiciones compuestas
- **Estructuras Anidadas**: Implementación de condicionales dentro de otros condicionales para lógica compleja
- **Formato Visual**: Uso de emojis y estructuras de texto para mejorar la legibilidad y comprensión
- **Comentarios Descriptivos**: Documentación clara del propósito y funcionamiento de cada sección de código

## 💻 Uso del Material

### Requisitos Previos

- **Software**: PSEint (versión actualizada)
- **Conocimientos**: Conceptos básicos de algoritmos (variables, entrada/salida)
- **Hardware**: Cualquier computadora capaz de ejecutar PSEint

### Cómo Utilizar la Guía

1. **Instalación de PSEint**:
   - Descargar PSEint desde [http://pseint.sourceforge.net/](http://pseint.sourceforge.net/)
   - Instalar siguiendo las instrucciones para tu sistema operativo

2. **Trabajo con los Algoritmos**:
   - Copiar y pegar los algoritmos completos en PSEint
   - Ejecutar cada algoritmo presionando F9 o el botón de ejecución
   - Verificar los resultados con los casos de prueba proporcionados
   - Experimentar modificando los valores de entrada o la lógica condicional

3. **Aprendizaje Progresivo**:
   - Comenzar con las implementaciones básicas (condicional simple, completa, múltiple)
   - Avanzar hacia las aplicaciones prácticas (par/impar, calculadora de descuentos, etc.)
   - Explorar el caso de estudio del sistema de recomendación de películas
   - Finalizar con los retos técnicos para consolidar conocimientos
   - Intentar resolver los retos por cuenta propia antes de revisar las soluciones

### Personalización de Ejercicios

Estos algoritmos están diseñados para ser puntos de partida. Se recomienda:

- Modificar los mensajes y formato de salida para hacerlos más informativos
- Agregar validaciones adicionales para mejorar la robustez del código
- Combinar diferentes tipos de estructuras condicionales en un mismo algoritmo
- Extender la funcionalidad con características adicionales (por ejemplo, más monedas en el conversor)
- Intentar resolver los mismos problemas con enfoques alternativos

## 🚀 Puesta en Marcha

### Primeros Pasos

1. **Configuración de PSEint**:
   - Al abrir PSEint por primera vez, seleccionar el perfil "Estricto"
   - Configurar el idioma según preferencias
   - Familiarizarse con la interfaz y sus herramientas principales

2. **Ejecutando tu Primer Algoritmo**:
   - Abrir un nuevo archivo en PSEint
   - Copiar el código del algoritmo "Condicional Simple"
   - Presionar F9 o hacer clic en el botón de ejecución
   - Ingresar los valores solicitados y verificar el resultado
   - Modificar la condición para ver cómo cambia el comportamiento

3. **Visualización de Diagramas de Flujo**:
   - Después de escribir un algoritmo, presionar F8 para ver su diagrama de flujo
   - Estudiar cómo las estructuras condicionales se representan gráficamente
   - Observar las diferencias entre los distintos tipos de condicionales
   - Entender el flujo lógico del algoritmo a través de su representación visual

## 📊 Análisis Comparativo de Estructuras Condicionales

| Tipo de Condicional | Casos de Uso                                           | Ventajas                                 | Consideraciones                                  |
| ------------------- | ------------------------------------------------------ | ---------------------------------------- | ------------------------------------------------ |
| **Simple** 🔀        | Verificaciones únicas, validaciones básicas            | Sencilla, directa, fácil de implementar  | No maneja el caso contrario explícitamente       |
| **Completa** 🔄      | Decisiones binarias, escenarios mutuamente excluyentes | Cubre ambos casos posibles, más completa | Mayor cantidad de código que la simple           |
| **Múltiple** 🌳      | Clasificaciones, evaluaciones con múltiples criterios  | Muy versátil, maneja muchos escenarios   | Puede volverse compleja y difícil de mantener    |
| **Anidada** 🪆       | Decisiones secuenciales, clasificaciones jerárquicas   | Permite lógica sofisticada               | Riesgo de excesiva complejidad y difícil lectura |

### Operadores Lógicos y Su Aplicación

| Operador   | Símbolo | Aplicación Práctica                             | Ejemplo                                 |
| ---------- | ------- | ----------------------------------------------- | --------------------------------------- |
| **Y/AND**  | &&      | Verificar múltiples condiciones simultáneamente | Comprobar edad Y posesión de licencia   |
| **O/OR**   | \|\|    | Verificar alternativas, al menos una condición  | Verificar si es feriado O fin de semana |
| **NO/NOT** | !       | Invertir el resultado de una condición          | Verificar si NO está lloviendo          |
