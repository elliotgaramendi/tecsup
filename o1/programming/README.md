# [💻 Programming Fundamentals 💻](https://github.com/elliotgaramendi/tecsup/tree/develop/o1/programming)

[![Programming](https://i.redd.it/v7g6ime1wtk61.jpg)](https://github.com/elliotgaramendi/tecsup/tree/develop/o1/programming)

## 📜 Descripción 📜
🚀 Aprende los fundamentos de la programación con Python a través de este curso integral. 💡 Desde diagramas de flujo y pseudocódigo hasta programación orientada a objetos y gráficos, domina conceptos clave aplicados a problemas reales. 🌍✨

## 💻 Instalación 💻

1. Descarga [Python](https://www.python.org/downloads/).
2. Instala el editor de texto [Visual Studio Code](https://code.visualstudio.com/).
3. Configura un entorno de desarrollo:
   - Instala la extensión `Python`.
   - Ejecuta los códigos desarrollados.

## 💡 Recomendaciones 💡

- 🛠️ **Crea diagramas de flujo y pseudocódigo:** Facilita el diseño de soluciones antes de implementar el código.
- 📚 **Aprende haciendo:** Resuelve problemas prácticos y aplica lo aprendido en cada unidad.
- 🐙 **Crea un portafolio en GitHub** para documentar tu progreso y mostrar tus proyectos.

## 🎯 Contenido del Curso 🎯

1. Diagramas de flujo y pseudocódigo
2. Control de flujo (bifurcaciones y bucles)
3. Sintaxis básica y operadores
4. Listas, tuplas y diccionarios
5. Funciones y módulos
6. Gestión de archivos
7. Introducción a POO
8. Gráficos con Python
9. Sustentación de proyecto final
