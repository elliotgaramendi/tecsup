## 📜 ¿Cómo usar este repositorio? 📜
1. 🔍 **Explora** los módulos y elige el que más te interese.
2. 📥 **Clona el repositorio** en tu máquina local:
 - ```git clone https://github.com/elliotgaramendi/tecsup.git```
3. 📂 **Accede al curso** que quieres estudiar:
 - ```cd ./tecsup/o1/frontend```
4. 📖 **Sigue las instrucciones** del **README.md** dentro de cada curso.

💡 **Aprende paso a paso con teoría y práctica.** 🚀
