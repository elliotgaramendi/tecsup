# 📘 Examen de Estructuras de Datos y Algoritmos en Python 🧠🐍

Este proyecto contiene la resolución completa del **examen final** de estructuras de datos y algoritmos, orientado a estudiantes de programación intermedia en Python. Cada sección evalúa competencias específicas mediante implementaciones limpias, eficientes y bien documentadas, con una fuerte presencia de pruebas automatizadas.

---

## 📂 Contenido del Proyecto

| Grupo | Tema Principal                                 | Descripción                                                                 |
| ----- | ---------------------------------------------- | --------------------------------------------------------------------------- |
| 1     | Diseño de Algoritmos y Análisis de Complejidad | Funciones con diferentes complejidades (O(1), O(n), O(log n), O(n^2))       |
| 2     | Recursividad y Backtracking                    | Implementaciones clásicas usando técnicas recursivas y combinatorias        |
| 3     | Listas Enlazadas (Linked Lists)                | Creación, manipulación y recorrido de listas enlazadas simples              |
| 4     | Pilas (Stacks)                                 | Pilas basadas en listas, arreglos, nodos enlazados y aplicaciones prácticas |

---

## 🚀 Tecnologías Usadas
- Lenguaje: **Python 3.11+**
- No se utilizan librerías externas
- Se emplean pruebas automáticas con `test(...)` basado en `print(✅/❌)`

---

## 🧪 Estructura de Evaluación
Cada ejercicio está evaluado con **5 pruebas automatizadas** que validan:
- Casos funcionales simples y complejos
- Comprobaciones de tipo (ej. `isinstance(..., int)`)
- Casos límite y validaciones adicionales

## 📈 Nomenclatura de Pruebas
Cada test sigue el formato `G.P.T`, donde:
- `G`: Número de grupo (1 a 4)
- `P`: Número de problema dentro del grupo
- `T`: Número de prueba

Ejemplo:
```python
test("2.3.4 fibonacci(10)", fibonacci(10) == 55)
```
