# 📚 Heap Mastery Toolkit

A hands-on collection of **heap challenges** and a complete **Python implementation** with tests to help you master MinHeaps, MaxHeaps and related algorithms. Perfect for interview prep and real-world applications! 🚀

---

## 📂 Files

- **guide.md**  
  • Step-by-step technical challenges (5 progressive tasks) for MinHeap & MaxHeap  
  • Problem statements, descriptions, base code, tips & motivation  
  • Lightweight and emoji-rich to keep students engaged 🎉

- **main.py**  
  • Full Python implementations of all 5 Technical Challenges  
  • Two bonus problems: *merge_k_sorted* & *sliding_window_median*  
  • AI-Powered Special Project: *Chanchirata Menu Optimizer*  
  • Integrated `record_test()` harness and final test summary 📋

---

## ⚙️ Setup

1. Clone or download this repo.  
2. Ensure you have Python 3.x installed.  
3. (Optional) Create and activate a virtual environment:
    ```bash
    python3 -m venv venv
    source venv/bin/activate
    ```

---

## 🚀 Usage

1. **Read the guide**
   Open `guide.md` in your favorite Markdown viewer or editor to explore the challenges.

2. **Run all tests**
   Execute the Python script to verify every implementation:

   ```bash
   python main.py
   ```

   You should see a ✅/❌ summary for each test and a final tally.
