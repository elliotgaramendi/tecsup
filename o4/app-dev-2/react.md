## 🗓️ Curso: React Developer Pro – De Cero a Producción

---

### 🔹 Semana 9: Introducción a React 🚀🧠💡💻

**Tema principal:** React como ecosistema declarativo moderno

#### 🧩 Temas:

* ❓ ¿Qué es React? ¿Por qué es declarativo?
* ⚙️ Setup del proyecto con **Vite + JSX**
* 🧾 Configuración inicial del `index.html`: `<title>`, favicon, estructura mínima
* 🪄 JSX básico: interpolaciones, atributos, expresiones
* 🧱 Functional components simples
* 📦 Props básicas

#### 🌐 Temas transversales:

* 🛡️ **Seguridad:** Sanitización de datos con `{safeString}`
* ♿ **Accesibilidad inicial:** etiquetas HTML5 mínimas (`<main>`, `<header>`)
* 🎯 **Buenas prácticas:** estructura limpia desde el inicio
* 🧠 **Arquitectura:** estructura base del proyecto por convenciones

#### 🔧 Reto:

* Crear `Header`, `HeroBanner` y `MovieTeaser` con datos hardcodeados

---

### 🔹 Semana 10: Componentes, Props, Estado y Eventos 🧩⚡📦🧱

**Tema principal:** Interactividad, composición y lógica interna

#### 🧩 Temas:

* 🧱 Componentes reutilizables con props dinámicas
* 📦 Props anidadas, destructuring y defaults
* ⚡ `useState` y manejo de eventos (`onClick`, `onChange`, `onSubmit`)
* 🔁 Renderizado condicional (`&&`, ternarios, fallback)
* 📋 Renderizado de listas (`.map`, keys, index)

#### 🌐 Temas transversales:

* ♿ **Accesibilidad:** navegación por teclado, uso correcto de roles en botones
* 🎯 **Buenas prácticas:** separación de lógica vs UI
* 🛡️ **Seguridad:** validación de inputs y control de eventos inseguros

#### 🔧 Reto:

* Galería de películas con favoritos (toggle visual)

### 🔹 Semana 11: Hooks Modernos y Librerías Esenciales 🪝🧠📚🎨

**Tema principal:** Modularidad, abstracción y herramientas reales de UI

#### 🧩 Temas:

* 🪝 `useEffect` y ciclo de vida moderno
* 🪝 Custom hooks (`useTheme`, `useFavorites`)
* 🎨 Tailwind CSS + CSS Modules (naming, responsive, dark mode)
* 📚 Librerías clave: Axios, React Hook Form, classnames

#### 🌐 Temas transversales:

* 🎯 **Buenas prácticas:** código DRY, hooks reutilizables
* ♿ **Accesibilidad:** formularios accesibles con etiquetas y validación semántica
* 🛡️ **Seguridad:** formularios con validación local segura
* 🧠 **Arquitectura:** separación clara de lógica en hooks personalizados

#### 🔧 Reto:

* Formulario de búsqueda con validación + estilo moderno

### 🔹 Semana 12: Fetching y Routing 🔄🗺️📡📁

**Tema principal:** Conexión a APIs reales + navegación SPA moderna

#### 🧩 Temas:

* 📡 Consumo de APIs con Axios (`/services`)
* 🔄 `useEffect` con fetching y loaders
* 🗺️ React Router: rutas públicas y dinámicas (`/movies/:slug`)
* 💤 Lazy loading y Suspense (`lazy`, `fallback`)
* 📁 Organización del proyecto por features

#### 🌐 Temas transversales:

* 🛡️ **Seguridad:** ocultar API keys con `.env`, control de errores
* ♿ **Accesibilidad:** estructura semántica entre páginas
* 🎯 **Buenas prácticas:** código modular por rutas

#### 🔧 Reto:

* Detalle dinámico de película con carga asincrónica
